📊 Personal Life Analytics

📌 Overview

Personal Life Analytics is a Python-based data analysis project that helps users track and analyze their daily life using data. The project organizes information related to productivity, health, habits, and personal finance, then performs data cleaning and exploratory data analysis (EDA) to generate meaningful insights through visualizations.

This project is currently under development. Dashboard and Machine Learning features will be added in future versions.

---

✨ Features

- Daily data collection using CSV files
- Separate datasets for:
  - 📚 Productivity
  - ❤️ Health
  - ✅ Habit Tracking
  - 💰 Finance
- Data cleaning using Pandas
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib, Seaborn, and Plotly
- Modular project structure for easy maintenance
